# spiekbrief Git en Github
## 1. clone, commit push en pull

een clone is een online repository naar je computer kopieren.
een Commit is een wijziging opslaan in de geschiedenis.
met een push kan je je wijzigingen van je computer naar GitHub sturen.
met een pull kan je wijzigingen van GitHub naar je computer halen.

## 2. Een goed commitbericht 

goed voorbeeld: "Spiekbrief: uitleg over clone toegevoegd". Dit is goed omdat je weet wat er veranderd is.

slecht voorbeeld: "aanpassing". Dit is slecht omdat je niet weet wat er veranderd is.

## 3. Gitignore

Gitignore zorgt ervoor dat bepaalde bestanden niet worden bijgehouden door Git.

## 4. Pull

de zin die ik in mijn github.com had geschreven kwam tevoorschijn in README.md.
en je kan best pullen om te kijken of iemand aanpassingen heeft gedaan anders kan het verloren geraken.
